개요

재직 중인 회사에서 두 개의 핵심 프로젝트를 전담 개발했습니다.
나노종합기술원 FileBrowsingSystem에서 PC Agent 측과 FileBrowsingSystem server 개발을 전담하여 비동기 아키텍처 설계, 신뢰성 있는 시스템 구현, 시큐어 코딩, 배포 및 테스트를 적용했습니다.
삼성전자 온양사업장 장비 데이터 수집 시스템에서 PC Agent 부분 개발을 전담하여 설정 기반의 확장성 있는 아키텍처 설계, 데이터 표준화, Windows Task를 통한 파일 롤링을 구현했습니다.
Spring Boot, Next.js, JSch, Shell Script, Spring Integration, Batch 등 다양한 기술 스택을 활용하여 상용 소프트웨어 개발의 전체 라이프사이클을 경험했습니다.

1 카이스트 나노종합기술원 - File Browsing System (FBS) 개발

Spring Boot JSch Next.js React MyBatis MariaDB JUnit
담당 업무
나노종합기술원 FileBrowsingSystem에서 PC Agent 측과 FileBrowsingSystem server 개발을 전담했습니다. 반도체 공정 장비에서 실시간으로 발생하는 대용량 데이터 파일을 외부 서버로 안정적으로 전송하고, 수집된 메타데이터를 웹 UI를 통해 효율적으로 관리하는 시스템을 개발했습니다.

주요 업무 및 성과

  • 비동기 아키텍처 설계 및 도입으로 시스템 성능 개선
    기존 동기 방식의 문제점(구현 복잡성, 스레드 고갈, 타임아웃)을 분석하고, 비동기 Webhook 아키텍처를 직접 설계하여 제안했습니다.
    Agent가 요청 수신 즉시 응답하고 별도 스레드에서 전송을 처리하도록 구현하여 클라이언트 대기 시간을 90% 단축하고 시스템 처리 효율성을 크게 향상시켰습니다.
  • 데이터 무결성 보장을 위한 다층적 방어 로직 구현
    반도체 공정 데이터의 단 하나의 유실도 허용되지 않는 특성을 고려하여 원격/로컬 파일의 체크섬 비교 및 파일 크기 기반 Fallback 검증 로직을 구현했습니다.
    또한 설정 기반 재시도 메커니즘과 보상 로직을 통해 일시적 네트워크 오류에 대응하여 데이터 무결성을 100% 보장했습니다.
  • 코드 품질 향상 및 유지보수성 개선
    Spring AOP를 활용한 Global Exception Handler 구현으로 예외를 일괄 처리하고, 비즈니스 예외를 계층화하여 코드 가독성을 높였습니다.
    또한 패키지별·레벨별 로그 분리 시스템을 구축하여 디버깅 편의성을 극대화했으며, 핵심 비즈니스 로직에 대한 단위/통합 테스트를 작성하여 코드 변경 시 잠재적 버그를 빌드 단계에서 조기 발견할 수 있는 체계를 마련했습니다.
  • 대용량 데이터 처리 성능 최적화
    수십만 건 이상의 데이터 조회를 대비하여 서버 사이드 페이지네이션과 무한 스크롤을 구현했습니다.
    Tanstack Query를 활용한 데이터 캐싱 및 상태 관리로 사용자가 새로고침 없이 실시간으로 데이터를 확인할 수 있는 반응형 UI를 구현하여 사용자 경험을 크게 향상시켰습니다.
  • 운영 효율화 및 문제 해결
    tcpdump 패킷 분석과 테스트 환경 재현을 통해 원인 불명의 전송 실패 이슈의 근본 원인을 규명하고 해결했습니다.
    격리된 내부망 환경을 고려하여 의존성을 포함한 패키징과 배포·패치·실행 자동화를 위한 Shell Script와 Batch를 작성하여 수동 배포로 인한 휴먼 에러를 방지하고 운영 편의성을 크게 향상시켰습니다.

2 삼성전자 온양사업장 - 반도체 장비 데이터 수집 및 전송 프로그램 개발

Spring Boot Spring Integration NSIS Gradle Batch Windows Task Scheduler
담당 업무
삼성전자 온양사업장 장비 데이터 수집 시스템에서 PC Agent 부분 개발을 전담했습니다. 제조사가 다른 여러 반도체 장비에서 생성되는 각기 다른 포맷의 데이터 파일을 실시간으로 수집하고, 이를 표준화된 형식으로 파싱하여 외부 서버로 전송하는 데이터 수집 프로그램을 개발했습니다.

주요 업무 및 성과

  • 확장 가능한 데이터 파이프라인 아키텍처 설계
    다양한 비표준 데이터 포맷에 유연하게 대응하기 위해 소스 코드 수정 없이 프로퍼티 설정만으로 새로운 데이터 형식을 추가할 수 있는 파서 구조를 설계했습니다.
    또한 단순 원시 타입(String) 대신 도메인 타입별 클래스를 도입하여 데이터 유효성을 컴파일 시점부터 보장하고, 휴먼 에러를 원천적으로 차단하여 시스템 안정성을 크게 향상시켰습니다.
  • Spring Integration 기반 데이터 처리 프로세스 자동화
    Spring Integration을 활용하여 파일 시스템 모니터링부터 파싱, 표준화, 유효성 검증, JSON 직렬화, 외부 서버 전송으로 이어지는 전체 파이프라인을 구축했습니다.
    신규 파일 발생 시 모든 데이터 처리 과정이 이벤트 기반으로 자동 수행되도록 하여 안정적인 데이터 수집 체계를 구축했습니다.
  • 운영 효율성 극대화를 위한 자동화 기능 구현
    장기적인 운영 관점에서 디스크 사용량과 같은 잠재적 문제를 사전에 방지하기 위해 처리 결과에 따른 파일 자동 분류 및 롤링 정책을 적용했습니다.
    Windows Task Scheduler에 자동으로 등록/제거하는 Batch 스크립트를 작성하여 운영 리소스를 최소화하고 자동화된 운영 체계를 구축했습니다.
  • 사용자 편의성 극대화를 위한 패키징 자동화
    Gradle과 NSIS 스크립트를 연동하여 버전 정보 자동 추적 및 원클릭 Installer 생성 환경을 구축했습니다.
    JRE를 내장하여 사용자 PC의 환경 종속성을 제거하고, 주요 설정을 외부 파일로 분리하여 재컴파일 없이 설정 변경이 가능하도록 구현하여 사용자 편의성을 크게 향상시켰습니다.
